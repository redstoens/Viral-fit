# Viral-fit 🚀

Threads 바이럴 게시물 자동 수집 + AI 글 생성 + 자동 발행 Chrome 확장 프로그램

---

## 주요 기능

- **바이럴 수집** — 조회수 1만+ Threads 게시물 자동 수집
- **AI 글 생성** — 바이럴 구조 분석 후 Claude / GPT-4o로 새 글 작성
- **이미지 처리** — DALL-E 3 생성 / 바이럴 이미지 재활용 / 직접 업로드
- **자동 발행** — 즉시 발행 또는 예약 발행 (chrome.alarms 기반)
- **데이터 내보내기** — 수집 게시물 CSV 저장

---

## 설치 방법

1. 이 저장소를 ZIP으로 다운로드 후 압축 해제
2. Chrome 주소창에 `chrome://extensions` 입력
3. 우측 상단 **개발자 모드** ON
4. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
5. 압축 해제한 폴더 선택

---

## 사용 방법

### 1. API 키 설정 (필수)

확장 아이콘 클릭 → **설정 탭**에서 입력

| 키 | 용도 | 발급처 |
|----|------|--------|
| Anthropic API 키 | Claude AI 글 생성 | [console.anthropic.com](https://console.anthropic.com) |
| OpenAI API 키 | GPT-4o 글 생성 + DALL-E 이미지 | [platform.openai.com](https://platform.openai.com/api-keys) |

> Claude만 사용할 경우 OpenAI 키는 입력하지 않아도 됩니다.

---

### 2. 바이럴 게시물 수집

1. [threads.net](https://www.threads.net) 로그인 후 탐색 피드 열기
2. 확장 아이콘 → **수집 탭**
3. 설정 입력:
   - 최소 조회수: `10000`
   - 목표 수집량: `20` (처음엔 적게 권장)
   - 딜레이: `2000ms` 이상
4. **수집 시작** 클릭
5. 수집 완료 후 CSV로 내보내기 가능

---

### 3. AI로 새 글 생성

1. **AI 생성 탭** 이동
2. 기반 게시물 선택 또는 **전체 분석** (수집 게시물 패턴 종합)
3. AI 모델 선택 (Claude / GPT-4o)
4. 추가 지시사항 입력 (선택사항)
   - 예시: `"공감 가는 톤으로, 마지막에 질문 추가"`
5. **AI로 글 생성** → 마음에 들면 **발행 큐에 추가**

---

### 4. 이미지 첨부 및 발행

**발행 큐 탭**에서 이미지 첨부:

| 방법 | 설명 |
|------|------|
| 직접 업로드 | PC에서 이미지 파일 선택 |
| 바이럴 이미지 선택 | 수집된 게시물 이미지 재활용 |
| DALL-E 생성 | 텍스트 설명으로 AI 이미지 생성 |

**발행 방법:**
- **즉시 발행** — Threads 탭이 열려있는 상태에서 클릭
- **예약 발행** — 날짜/시간 선택 후 큐에 추가 → 지정 시간에 자동 발행

---

## 주의사항

### 계정 안전
- 딜레이는 반드시 **2000ms 이상** 유지 (미만 설정 시 봇 감지 위험)
- 하루 발행 횟수 **10~20개 이내** 권장
- 수집과 발행을 같은 날 대량으로 반복하지 말 것

### 예약 발행
- 예약 시간에 **Chrome이 실행 중이어야** 발행됨
- Threads 탭이 없으면 자동으로 새 탭을 열어 발행 시도

### API 비용 참고
- Claude: 글 1개 생성 약 $0.01~0.03
- DALL-E 3: 이미지 1장 약 $0.04~0.08

### 알려진 한계
- Threads UI 업데이트 시 수집/발행 셀렉터 수동 수정 필요
- 피드에서 조회수가 숨겨진 경우 수집 시 0으로 처리됨
- 이미지 자동 첨부가 안 될 경우 텍스트 발행 후 이미지 수동 첨부
